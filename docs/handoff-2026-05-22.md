## Hardware Facts Confirmed

Fixed soldered pin map:

| Function | Pin |
| --- | --- |
| I2C SDA | GPIO5 |
| I2C SCL | GPIO6 |
| DHT11 DATA | GPIO4 |
| Servo signal | GPIO3 |
| Fan PWM blue | GPIO10 |
| MODE button OUT | GPIO0 |
| UP button OUT | GPIO1 |
| DOWN button OUT | GPIO7 |

Confirmed behavior:

- Buttons are active HIGH.
- OLED address is `0x3C`.
- INA219 address is `0x40`.
- INA219 wiring: VIN- is BMS P+, VIN+ is load-side positive.
- Fan PWM is not inverted.
- Fan PWM boot safety works: GPIO10 forced LOW, fan remains stopped.
- Fan 25% starts the fan; fan 0% stops it.
- Servo sweep is disabled at boot.
- MODE long press toggles servo sweep.
- UP/DOWN enter MANUAL immediately. Short presses move fan speed through
  `0, 15, 30, 45, 60, 75, 90, 100`; from `100`, DOWN goes to `90`.
  Holding repeats one-percent fan adjustments without applying the short-press
  boundary jump.

## Recent Firmware Features

Committed firmware already includes:

- Staged PlatformIO environments:
  - `button_test`
  - `i2c_scan`
  - `oled_test`
  - `ina219_test`
  - `dht_test`
  - `fan_pwm_test`
  - `servo_test`
  - `integrated`
- OLED screen:
  - Mode
  - Battery percent
  - Large fan percent
  - Temperature
  - Humidity
  - Voltage
  - Remaining time estimate
  - Servo state
- Battery display filtering:
  - raw voltage and raw percent are logged
  - filtered voltage and filtered percent are used for display
  - load sag is reflected slowly to reduce large swings under fan load
- Remaining time estimate:
  - calculated from filtered battery percent and configured power constants
  - this is only an estimate until pack capacity and fan power are measured
- DHT temperature offset support:
  - current offset is `DHT_TEMP_OFFSET_C = -2.6f`
  - this came from one trusted comparison: fanmate displayed `28.6C` while the
    room thermometer read `26.0C`
- AUTO fan curve:
  - corrected, smoothed DHT temperature maps 22C to 0%, 26C to 13%, 34C to
    50%, and 44C to 100%
  - the 34C point is intentionally middle speed instead of near full speed
- Preferences-backed restore:
  - after safe fan PWM and servo initialization, integrated firmware restores
    the last app mode, MANUAL fan percent, last AUTO fan percent, servo sweep
    state, and servo angle
  - if AUTO is restored, the last AUTO fan percent is applied provisionally
    until the first valid DHT sample arrives
  - failed DHT reads before the first valid sample do not clear that provisional
    AUTO output
  - MANUAL fan writes are debounced for 2 seconds, AUTO fan output writes are
    limited to once per 30 seconds, and servo angle sweep writes are limited to
    once per 10 seconds; mode and sweep toggles are saved immediately
