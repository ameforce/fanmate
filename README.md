# fanmate
A compact desk fan project for smarter and more comfortable personal cooling.

## Firmware

The ESP32-C3 Super Mini firmware is a PlatformIO Arduino project. Start with the
staged hardware bring-up flow before flashing the integrated controller.

- Build target: `esp32-c3-devkitm-1`
- First upload stage: `button_test`
- Bring-up guide: [docs/bringup.md](docs/bringup.md)
